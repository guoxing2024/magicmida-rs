# x64dbg深度调试脚本 - 查找GUI不显示的原因

## 目标
调试 启动器_DATA_RESTORE.exe，找出为什么MainWindowHandle=0

## 调试步骤

### 1. 设置断点 - 窗口创建相关API

```
bp CreateWindowExA
bp CreateWindowExW
bp RegisterClassExA
bp RegisterClassExW
bp ShowWindow
bp UpdateWindow
bp DialogBoxParamA
bp DialogBoxParamW
bp CoInitialize
bp CoInitializeEx
```

### 2. 设置断点 - WinMain入口

```
bp 0x140001000
```

### 3. 运行并记录

```
g
```

每次断点命中时记录：
- 断点位置
- 参数值
- 返回值
- GetLastError

### 4. 关键检查点

#### A. WinMain是否执行？
```
bp 0x140001000
g
```

如果未命中 → OEP不正确

#### B. CoInitialize是否调用？
```
bp CoInitialize
bp CoInitializeEx
g
```

如果调用 → 检查返回值
如果未调用 → 可能是COM初始化问题

#### C. RegisterClassEx是否成功？
```
bp RegisterClassExW
g
```

命中后：
```
p
r rax  ; 检查返回值（!=0表示成功）
```

如果返回0：
```
? GetLastError()
```

#### D. CreateWindowEx是否调用？
```
bp CreateWindowExW
g
```

命中后查看参数：
```
dd rsp L20  ; 查看栈上参数
p
r rax  ; 检查返回值（窗口句柄，NULL表示失败）
```

如果返回NULL：
```
? GetLastError()
```

#### E. ShowWindow是否调用？
```
bp ShowWindow
g
```

命中后：
```
r rcx  ; 窗口句柄
r rdx  ; nCmdShow参数
```

### 5. 如果所有API都未调用

说明程序逻辑在到达GUI初始化前就终止了：

```
bp MessageBoxA
bp MessageBoxW
bp ExitProcess
g
```

检查是否有错误提示或静默退出

### 6. 内存检查

检查.data段是否正确恢复：

```
dump 0x140141000 L1000
```

查看关键全局变量的值

### 7. TLS Callback检查

```
bp 0x140eda000  ; bootstrap入口
g
```

单步执行bootstrap代码：
```
t  ; 单步
```

验证：
1. .data段恢复是否执行
2. 容器恢复是否执行
3. 是否有异常

### 8. 异常监控

```
seh on
g
```

如果有异常触发，记录异常类型和位置

## 预期结果

### 情况1: CreateWindowEx未调用
→ 程序逻辑未到达GUI初始化代码
→ 需要回溯找出在哪里终止

### 情况2: CreateWindowEx调用但返回NULL
→ 检查GetLastError
→ 参数问题或资源加载失败

### 情况3: CreateWindowEx成功但ShowWindow未调用
→ 窗口创建了但未显示
→ 逻辑问题

### 情况4: ShowWindow调用但窗口仍不可见
→ 可能是消息循环问题
→ 检查GetMessage/DispatchMessage

## 自动化脚本

```x64dbg
// 保存为 debug_gui.txt

// 设置所有断点
bp CreateWindowExW "log \"CreateWindowExW called\";g"
bp RegisterClassExW "log \"RegisterClassExW called\";g"
bp ShowWindow "log \"ShowWindow called: hWnd={rcx}, nCmdShow={rdx}\";g"
bp CoInitializeEx "log \"CoInitializeEx called\";g"
bp MessageBoxW "log \"MessageBoxW called\";g"
bp ExitProcess "log \"ExitProcess called: code={rcx}\";stop"

// 运行
g

// 如果程序退出且没有断点命中
log "No window creation APIs called!"
```

## 使用方法

1. 启动x64dbg
2. 打开 启动器_DATA_RESTORE.exe
3. 执行上述脚本或手动设置断点
4. F9运行
5. 记录所有断点命中情况
6. 分析结果
