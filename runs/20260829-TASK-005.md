## 四、三选一定级（唯一结论）

### 定级：(b) —— 0x8c4c0 静态存在但本批 trace 覆盖路径中未激活；ISA_SPEC_V0 的"trace 实证 216K+"标注有误，降级为"静态推断"

支撑数字（全部可复算）：
1. 三种口径（页起始精确 / 页区间包含 / 基本块入口级）0x8c000-0x8cfff exec **全为 0**，页内 unique=0 —— **不是**统计口径问题（若只是页起始精确匹配的假象，C 口径必然 >0）；
2. 0x8c4c0 / 0x8f0bb（静态 call 所在）/ 0x12d8c8（间接 call 槽）逐址 exec=0；
3. "216K+ trace 实证"的实际对象是 **0x8f099→0x8f374 238,672 次**，目标从不是 0x8c4c0；
4. 0x8c000-0x8cfff 位于两源 .text 最大执行空窗内（46KB 死区），0x8b800-0x8bfff 也无 exec，排除块级覆盖。
