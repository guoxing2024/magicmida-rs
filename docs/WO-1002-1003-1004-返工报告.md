## 二、技术缺陷修复

### B1. flaky 测试修复（config.rs:125 断言失败）

**缺陷原因:**  
测试直接操作进程环境变量（`std::env::set_var` / `remove_var`），与并行测试竞态导致 `mode_from_env_is_case_insensitive` 等测试失败

**修复方案:**  
1. 拆分纯函数 `from_env_value(Option<&str>)`，接受环境变量值而非直接读取
2. `from_env()` 调用纯函数并处理 `std::env::var` 的 IO
3. 测试只测纯函数，移除所有 `std::env::set_var` / `remove_var`
4. 全局状态测试仅验证读写能力，不假设环境变量值

**修复验证:**  
- 编译通过：`cargo check -p mida-packers-themida`
- 测试数量：8 个（from_env_value 6 个 + 全局状态 2 个）
- 无环境变量副作用，无并行竞态

**代码变更:**
```rust
// 修复前（flaky）
pub fn from_env() -> Self {
    match std::env::var("MIDA_ANTIDEBUG_MODE") { ... }
}

// 修复后（纯函数）
pub fn from_env_value(value: Option<&str>) -> Self { ... }
pub fn from_env() -> Self {
    let value = std::env::var("MIDA_ANTIDEBUG_MODE").ok();
    Self::from_env_value(value.as_deref())
}
```
