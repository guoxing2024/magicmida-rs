# 技术咨询简报 — WinLicense 保护 DLL 快照重建后的 VM 状态机卡死

- 出具: 2026-08-31 · 供外部专家咨询用 · 全部结论均有原始输出存档（见 §7）
- 标识: 宿主重建件 a852880a / core.dll 原版 09f3dd34 / 候选 r2 096f3bdf / 自举变体 7b470117（sha256 前 8 位）

## 0. 一句话

把一个 WinLicense（Themida 系）保护的 DLL 从运行态 dump → 固化 → 重建，重建件能加载、进程能存活，但壳的虚拟机状态机卡死（授权窗口不再出现）。请求评估：这是已知死路，还是有已知解法 / 工具 / 更优路线。

## 1. 样本与架构

- **宿主** exe（我方平台已脱壳重建的明文 PE；.text 前 ~0x2c00 为 CRT/引导明文，其后亦有 Themida VM 加密区）。
- **core.dll**：WinLicense 保护；21 个区段；`.winlice`（VM 字节码，熵 ≈6.15，线性反汇编无效）+ `.boot`（加密引导区，含壳入口 RVA 0x8a0108，区段范围 [0x8a0000, 0xdb1a00)）。
- **导出面恰好 2 个函数**：`GetAppVersion`、`Run`。宿主经 `LoadLibraryA` + `GetProcAddress` 消费；授权、下载、AddOns 部署全部在 core 内部完成（宿主静态导入 urlmon 零命中）。
- **后端**：`http://101.132.143.14:8000`（`/dll/core-version.json` 版本检查；`/download/clear.ps1`；AddOns 分发；JSON 键 `download_url` / `"success":false`）。磁盘原版 core 内该地址**全密文**（IP/`http://` grep 零命中），运行时由 VM 解密材料化。
- **原版本机表现**：加载 → 弹"PigToGoLicenseDialog"授权窗口等待输入。无有效注册码在手，窗口之后的行为从未测过。
- WinLicense 具体版本未指纹；如需要可提供区段布局细节。

## 2. 我方管线已解决的部分（请勿重复劳动）

1. **dump→固化→重建管线**：keep_runtime_base、DYNAMIC_BASE 清除、固定基址 0x7ffc57e30000。
2. **会话绝对指针（已修）**：重建件携带 dump 会话的 ~3500 个绝对指针 → 已全部重锚；自研普查器验证零残留（对齐命中的 sentinel/NaN/inherited/code-immediate/cross-field-RVA 五类豁免后 hard=0）。
3. **引导期 exit(0)（已修）**：固化时 EP 被写成 NOP stub（`31 c0 ff c0 c3`）→ 宿主查询壳状态失败 → CRT `_exit(0)`（DllMain 后 2.4ms，R11=0xc0000135，栈顶 msvcrt `_exit+0x89`，无宿主明文帧）。EP 字段改回壳入口 0x8a0108（实际字节差异 3 字节）后进程存活。
4. **宿主差异已排除**：新旧宿主 .text 逐字节一致；差异仅 .data/.bss/.idata 会话指针。

## 3. 当前卡点（C-10，2/2 可复现，调试器附加与非附加行为一致）

- 进程存活不退出、无 AV、无任何窗口。
- **1 个线程在 .winlice VM 区全速空转**（core+0x324317，单核 100%，CPU 时间线性增长）。
- **Run 线程 100% 阻塞在 NtWaitForSingleObject**（ntdll RVA 0x1603f0），等待的句柄从不触发；其余线程闲置于 ZwWaitForWorkViaWorkerFactory。
- urlmon 从未加载/调用；IAT 槽（0x7ffd1014e470，指向 URLDownloadToFileA）从未被改写；目标下载页零变化。
- VM 区静态不可达。

## 4. 我方当前理解（假设，未证）

- 重建件本质是**运行中某一刻的内存快照**；在新进程里重放的是"半材料化"的 VM 状态。
- VM 内部等待/信号逻辑无法在新会话时间线里完成——它在等一个只在原进程时间线里存在过的东西（解密完成事件？license 状态字？应由引导设置的内核对象？未知）。
- 空转线程是否就是 VM dispatcher/解码循环在工作、而卡点只在等待侧，未定。

## 5. 约束条件

- 快照指针重锚**绑定当前 boot 的模块基址**（ntdll 0x7ffd379e0000、kernel32 0x7ffd36600000 等）；重启即作废，需整套重产（管线存在，但每次消耗一个 boot 会话）。
- 研究红线：**不做授权校验击穿**（不造注册码、不 patch 授权逻辑、不做假授权服务器）；手上无有效注册码。
- 实验机全网出站阻断；可起 127.0.0.1 mock。
